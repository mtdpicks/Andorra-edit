Logo font: "Always in the Star" (BlackFridayFont, commercial licence).

1. Buy a licence that covers website (webfont) use.
2. Put the font file in this folder, named:
     always-in-the-star.woff2   (preferred)
   or
     always-in-the-star.otf
3. Upload the folder with the site. The logo switches to it automatically.

Until the file is here, the logo shows the Hurricane script as a fallback.
